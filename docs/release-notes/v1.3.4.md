ClipQR 1.3.4: ahora también en macOS y Linux.

## Instalación
- **Windows, desde la 1.2 o la 1.3:** ClipQR te avisará de la versión nueva y se instalará sola cuando aceptes. Tus ajustes se conservan.
- **Windows, nueva instalación:** **ClipQR-Setup.exe** (o **ClipQR.exe**, portátil). Si aparece SmartScreen: **Más información → Ejecutar de todas formas**.
- **macOS 11 o posterior (Apple Silicon):** **ClipQR-macOS.zip**. Descomprímelo, mueve ClipQR a *Aplicaciones* y la primera vez ábrelo con clic derecho › **Abrir**; aún no está firmado por Apple.
- **Linux (x86_64):** **ClipQR-Linux-x86_64.tar.gz**. Descomprímelo y ejecuta `./install.sh`. Necesita xclip o wl-clipboard.
- **Microsoft Store:** el paquete **.msix** de esta versión.
- **Comprobar la descarga:** `SHA256SUMS.txt`.

## Novedades
- **macOS y Linux:** lo mismo que en Windows (avisos, facturas, pagos, crear QR, historial, 10 idiomas), con el inicio automático, la Papelera y la Wi‑Fi de cada sistema.
  - En macOS vive en la barra de menús; los atajos son ⌃⌥⌘Q, ⌃⌥⌘G y ⌃⌥⌘Espacio.
  - En Linux funciona con X11 y Wayland. En Wayland no hay atajos globales ni escaneo de zona.
- **Borrar la captura al detectar un código:** activado por defecto y lo primero de la Configuración. Cada aviso indica que está activo, con un botón para desactivarlo. Las capturas van a la Papelera y se pueden recuperar.
- **Paquete MSIX para la Microsoft Store** en cada versión.

## Notas
- Esta es la primera versión para macOS y Linux. La de Linux se probó en Ubuntu. La de macOS solo con tests automáticos y la compilación, no en un Mac real: si algo falla, [abre una incidencia](https://github.com/MojeZcg/ClipQR/issues/new/choose).
- En macOS hay que permitir ClipQR en *Privacidad y seguridad › Accesibilidad* (atajos) y *Grabación de pantalla* (escanear una zona).

ClipQR 1.3.4: now on macOS and Linux too.

## Installation
- **Windows, from 1.2 or 1.3:** ClipQR will tell you about the new version and install it when you accept. Your settings are kept.
- **Windows, new installation:** **ClipQR-Setup.exe** (or **ClipQR.exe**, portable). If SmartScreen appears: **More info → Run anyway**.
- **macOS 11 or later (Apple Silicon):** **ClipQR-macOS.zip**. Unzip it, move ClipQR to *Applications*, and the first time open it with right-click › **Open**; it isn't signed by Apple yet.
- **Linux (x86_64):** **ClipQR-Linux-x86_64.tar.gz**. Extract it and run `./install.sh`. It needs xclip or wl-clipboard.
- **Microsoft Store:** this version's **.msix** package.
- **Verify the download:** `SHA256SUMS.txt`.

## What's new
- **macOS and Linux:** the same as on Windows (notifications, invoices, payments, create QR, history, 10 languages), with each system's start at login, Trash and Wi‑Fi.
  - On macOS it lives in the menu bar; the shortcuts are ⌃⌥⌘Q, ⌃⌥⌘G and ⌃⌥⌘Space.
  - On Linux it works on X11 and Wayland. Wayland has no global shortcuts or area scanning.
- **Delete the screenshot when a code is detected:** on by default and first in Settings. Every notification shows it's on, with a button to turn it off. Screenshots go to the Recycle Bin/Trash and can be restored.
- **MSIX package for the Microsoft Store** with every release.

## Notes
- This is the first macOS and Linux release. The Linux version was tested on Ubuntu. The macOS version was only checked with automated tests and the build, not on a real Mac: if something breaks, [open an issue](https://github.com/MojeZcg/ClipQR/issues/new/choose).
- On macOS, allow ClipQR under *Privacy & Security › Accessibility* (shortcuts) and *Screen Recording* (area scanning).
